# Warehouse Exporter

Приложение для выгрузки данных о складах из API МойСклад (MoySklad).

## Требования

- Python 3.8+
- PyQt5
- requests
- urllib3

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python app.py
```

## Использование

1. Введите API токен МойСклад (по умолчанию используется тестовый токен)
2. Нажмите "Применить" для обновления токена
3. Нажмите "Обновить список складов" для загрузки доступных складов
4. Выберите нужные склады из списка
5. Нажмите "Выгрузить выбранные склады"
6. Результат будет сохранён в JSON-файл с timestamp в названии

## Структура выходного файла

Приложение создаёт JSON-файл с данными о товарах на выбранных складах:
- Название товара
- Артикул (code)
- Количество
- Цена
- Единица измерения
- Ячейки хранения
